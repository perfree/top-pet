# 测试说明

## 单元测试

```bash
npm test
```

Node.js 18+，无 npm 依赖。共 15 项测试，覆盖空位计算、双向闪现、动态布局、满屏控件、边缘转向、喂食和捉迷藏状态、暂停以及图标位移传播和屏幕边界。

## 真实 GNOME 集成测试

```bash
bash tools/shell-test.sh
```

依赖 GNOME Shell 46、gsettings、gnome-extensions、dbus-run-session、Python 3，以及创建本地 D-Bus socket 和虚拟显示的权限。

脚本在临时目录创建独立 XDG 数据/配置/缓存/运行时目录与 D-Bus 会话，启动真实 GNOME Shell 46 + Wayland 虚拟显示。不替换当前桌面，不向日常桌面安装测试器。脚本结束后停止测试 Shell；临时目录和项目 `test-results/` 可用于排查问题。

默认虚拟显示为 2560×1600，内部界面缩放设为 2，可用 `PANEL_PET_TEST_MONITOR=1920x1080` 改变虚拟显示分辨率。这覆盖了开发桌面 X11 125% 分数缩放所使用的 2 倍界面坐标；虚拟测试会话本身不是 X11 125%。

测试器使用 Clutter 虚拟鼠标发送实际按下、释放和移动事件，验证：

- 扩展 ACTIVE、纹理加载、自适应尺寸、真实顶栏坐标和移动计时器。
- 左键摸摸、右键菜单、菜单喂食与顶栏原控件点击。
- 双向下沉、完全隐藏、越过真实控件、重新冒出。
- 点击赢得捉迷藏、概览期间隐藏与退出概览恢复。
- 图标实际位移、形成足够空位、宠物自动离开以及控件自动复位。
- 禁用后清理，以及重新启用无图层泄漏。

**不要将 `tools/shell-test@local` 安装到日常桌面。** 它仅是独立测试器，不包含在正式扩展安装包中。

## v0.1.0 验证结果

2026-09-13：15 项单元测试和 29 项真实 GNOME 集成断言全部通过。测试时顶栏高度为 64，宠物区域为 76×64，不再受旧版 32px 上限限制。

原始断言结果见 [runtime-report.json](runtime-report.json)，实际让位截图见 [runtime.png](images/runtime.png)。结果是特定环境下的验证，不代表支持所有显示协议、缩放或第三方扩展组合。

CI 运行单元测试、JavaScript 语法检查与构建完整性检查。真实 GNOME 集成测试需要图形会话环境，由维护者在本地运行。
