首个公开版本：把一只软萌卡皮巴拉放进 GNOME 顶栏。

## 功能

- 慢走、小跑、发呆，顶栏边缘自动转向。
- 遇到图标时向下隐藏，从另一侧向上冒出，支持双向闪现。
- 密集图标平滑让出空位，宠物离开后自动复位；屏幕边界不足时保留原位。
- 左键摸摸、右键菜单、喂胡萝卜、追逐、捉迷藏和暂停。
- 按顶栏高度自适应尺寸，移除 32px 上限，改善高分屏缩放下的可见大小。

## 下载与安装

**GNOME Shell 46 / Zorin OS 18 用户下载 `panel-pet@local.shell-extension.zip`**，在下载目录执行：

```bash
gnome-extensions install --force panel-pet@local.shell-extension.zip
```

保存工作后注销并重新登录，再启用：

```bash
gnome-extensions enable panel-pet@local
```

`top-pet-preview.html` 可直接用浏览器打开试玩，无需安装。`SHA256SUMS` 可用于校验安装包与试玩页。GitHub 自动生成的 Source code 文件是源码，不是扩展安装包。

## 验证与限制

15 项单元测试与 29 项真实 GNOME 集成断言通过。集成测试使用 GNOME Shell 46、2560×1600 Wayland 虚拟显示、2 倍内部界面缩放和虚拟鼠标。

当前仅支持主屏原生 GNOME 46 顶栏；KDE、Xfce、其他 GNOME 版本及全部第三方顶栏组合尚未适配。饱食和心情暂不跨会话保存。更新后需要重新登录以加载新代码。

GitHub 版本：v0.1.0；GNOME 扩展整数版本：3。
